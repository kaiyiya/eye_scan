This is the dataset proposed & analyzed in the following paper:

Sitzmann, Vincent, et al. "Saliency in VR: How do people explore virtual environments?." IEEE Transactions on Visualization and Computer Graphics (2017).

Link to the paper preprint:
http://ieeexplore.ieee.org/document/8269807/

Code to use this dataset can be found in the github repository:
https://github.com/vsitzmann/vr-saliency

Simply clone the repository and place this extracted "data" directory at the project root (at the same level as the "src" and "docs" directories.)
