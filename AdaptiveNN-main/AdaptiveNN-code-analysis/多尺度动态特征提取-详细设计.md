## 🏗️ 宏观架构设计

### 设计理念

**核心思想**：将AdaptiveNN的"从粗到细"感知机制引入ScanDMM，实现动态、自适应的特征提取。

**关键变化**：
- ❌ **原始**：一次性提取全图特征，所有时间步相同
- ✅ **改进**：初始粗特征 + 动态细特征，根据注视点提取局部信息

### 步骤2：状态转移

#### 原始 ScanDMM

```python
for t in pyro.markov(range(1, T_max + 1)):
    # 所有时间步使用相同的img_features
    z_mu, z_sigma = self.trans(z_prev, img_features)
    #                                    ↑
    #                              固定不变
    #                              (B, 100)
    
    z_t = pyro.sample("z_%d" % t, dist.Normal(z_mu, z_sigma))
    z_prev = z_t
```

**特点**：
- `img_features`在所有时间步都是相同的
- 无法根据当前注视点动态调整
- 状态转移只依赖隐状态z_{t-1}和固定的图像特征

#### 改进后 AdaptiveScanDMM

```python
# 初始：使用粗特征
s_coarse = self.coarse_cnn(images)  # (B, 50)

for t in pyro.markov(range(1, T_max + 1)):
    # 根据当前注视点动态提取细特征
    if t == 1:
        # 第一个时间步：使用粗特征（扩展）
        current_img_features = F.pad(s_coarse, (0, 50))  # (B, 100)
    else:
        # 后续时间步：提取局部细特征并融合
        x_t_prev = x_t  # 上一个时间步的注视点
        local_patch = extract_region(images, x_t_prev)  # (B, 3, 64, 64)
        s_fine = self.fine_cnn(local_patch)  # (B, 50)
        
        # 特征融合
        current_img_features = self.feature_fusion(s_coarse, s_fine)  # (B, 100)
        #                                    ↑              ↑
        #                                全局粗特征      局部细特征
    
    # 使用动态的图像特征
    z_mu, z_sigma = self.trans(z_prev, current_img_features)
    #                                    ↑
    #                              每个t不同
    #                              (B, 100)
    
    z_t = pyro.sample("z_%d" % t, dist.Normal(z_mu, z_sigma))
    
    # 生成当前注视点
    x_mu, x_sigma = self.emitter(z_t)
    x_t = pyro.sample("obs_x_%d" % t, dist.Normal(x_mu, x_sigma))
    
    z_prev = z_t
```

**关键差异**：
- ✅ 每个时间步使用不同的`current_img_features`
- ✅ 初始阶段：粗特征（全局上下文）
- ✅ 后续阶段：粗+细特征融合（全局+局部）
- ✅ 状态转移考虑了当前注视点的局部信息

### 步骤3：特征融合机制

#### 方案A：简单拼接（MVP推荐）

```python
class SimpleFeatureFusion(nn.Module):
    """简单拼接：粗特征 + 细特征 = 100维"""
    def forward(self, s_coarse, s_fine):
        # s_coarse: (B, 50) - 全局粗特征
        # s_fine: (B, 50) - 局部细特征
        s = torch.cat([s_coarse, s_fine], dim=1)  # (B, 100)
        return s
```

**优点**：
- 实现简单
- 无需额外训练
- 快速验证可行性

**缺点**：
- 可能不是最优融合方式
- 粗特征和细特征权重相同

#### 方案B：加权融合

```python
class WeightedFeatureFusion(nn.Module):
    """加权融合：可学习的权重"""
    def __init__(self, z_dim=100):
        super().__init__()
        self.alpha = nn.Parameter(torch.tensor(0.5))  # 可学习权重
    
    def forward(self, s_coarse, s_fine):
        # 加权求和
        s = self.alpha * s_coarse + (1 - self.alpha) * s_fine  # (B, 50)
        # 扩展到100维
        s = F.pad(s, (0, 50))  # (B, 100)
        return s
```

**优点**：
- 可以学习最优权重
- 更灵活

**缺点**：
- 需要额外训练
- 维度需要扩展

#### 方案C：学习融合（推荐完整版）

```python
class LearnedFeatureFusion(nn.Module):
    """学习融合：使用MLP学习融合方式"""
    def __init__(self, z_dim=100):
        super().__init__()
        self.fusion = nn.Sequential(
            nn.Linear(z_dim, z_dim),  # 100 -> 100
            nn.ReLU(),
            nn.Linear(z_dim, z_dim)   # 100 -> 100
        )
    
    def forward(self, s_coarse, s_fine):
        # 拼接
        combined = torch.cat([s_coarse, s_fine], dim=1)  # (B, 100)
        # 学习融合
        s = self.fusion(combined)  # (B, 100)
        return s
```

**优点**：
- 可以学习复杂的融合方式
- 最灵活

**缺点**：
- 需要额外参数和训练
- 实现复杂度较高

### 1. AdaptiveSphere_CNN

#### 宏观设计

```python
class AdaptiveSphere_CNN(nn.Module):
    """
    自适应球面CNN：支持多尺度动态特征提取
    
    功能：
    1. 粗粒度特征提取（Glance阶段）
    2. 细粒度特征提取（Focus阶段）
    3. 特征融合
    """
    def __init__(self, z_dim=100):
        super().__init__()
        self.z_dim = z_dim
        
        # 粗粒度CNN（轻量级或降采样）
        self.coarse_cnn = Sphere_CNN(out_put_dim=z_dim // 2)  # 50维
        
        # 细粒度CNN（标准）
        self.fine_cnn = Sphere_CNN(out_put_dim=z_dim // 2)  # 50维
        
        # 区域提取器
        self.region_extractor = RegionExtractor()
        
        # 特征融合
        self.feature_fusion = LearnedFeatureFusion(z_dim)
```

#### 详细实现

```python
class AdaptiveSphere_CNN(nn.Module):
    def __init__(self, z_dim=100, region_size=64):
        super().__init__()
        self.z_dim = z_dim
        self.region_size = region_size
        
        # ===== 粗粒度CNN =====
        # 选项1：使用降采样图像
        # 选项2：使用轻量级架构（减少层数或通道数）
        # 选项3：使用标准Sphere_CNN但输出50维
        self.coarse_cnn = Sphere_CNN(out_put_dim=z_dim // 2)  # 50维
        
        # ===== 细粒度CNN =====
        # 标准Sphere_CNN，但输入是局部patch
        self.fine_cnn = Sphere_CNN(out_put_dim=z_dim // 2)  # 50维
        
        # ===== 区域提取器 =====
        self.region_extractor = RegionExtractor(region_size=region_size)
        
        # ===== 特征融合 =====
        self.feature_fusion = LearnedFeatureFusion(z_dim)
    
    def forward(self, images, gaze_points=None, mode='coarse'):
        """
        前向传播
        
        Args:
            images: 输入图像 (B, 3, H, W)
            gaze_points: 注视点坐标 (B, 2) - 归一化坐标 [0, 1]，格式 (y, x)
            mode: 'coarse' | 'fine' | 'adaptive'
        
        Returns:
            features: 图像特征 (B, z_dim)
        """
        if mode == 'coarse':
            # Glance阶段：快速提取粗特征
            return self.coarse_cnn(images)  # (B, 50)
        
        elif mode == 'fine' and gaze_points is not None:
            # Focus阶段：提取局部细特征并融合
            # 1. 提取局部区域
            local_patches = self.region_extractor(images, gaze_points)  # (B, 3, 64, 64)
            
            # 2. 提取细特征
            s_fine = self.fine_cnn(local_patches)  # (B, 50)
            
            # 3. 提取粗特征（复用）
            s_coarse = self.coarse_cnn(images)  # (B, 50)
            
            # 4. 特征融合
            s = self.feature_fusion(s_coarse, s_fine)  # (B, 100)
            
            return s
        
        else:
            raise ValueError(f"Invalid mode: {mode}")
```

### 2. RegionExtractor（区域提取器）

#### 宏观设计

```python
class RegionExtractor(nn.Module):
    """
    区域提取器：从360度图像中提取注视点周围的局部区域
    
    功能：
    1. 处理360度图像的边界连续性
    2. 提取局部patch
    3. 处理球面几何（简化版或完整版）
    """
```

#### 详细实现（简化版 - MVP推荐）

```python
class RegionExtractor(nn.Module):
    """简化版：直接提取矩形区域，处理边界wrap"""
    def __init__(self, region_size=64):
        super().__init__()
        self.region_size = region_size
    
    def forward(self, images, gaze_points_2d):
        """
        从360度图像中提取注视点周围的局部区域
        
        Args:
            images: 输入图像 (B, 3, H, W)，例如 (64, 3, 128, 256)
            gaze_points_2d: 注视点坐标 (B, 2)，归一化坐标 [0, 1]，格式 (y, x)
        
        Returns:
            local_regions: 局部区域 (B, 3, region_size, region_size)
        """
        batch_size, channels, H, W = images.shape
        half_size = self.region_size // 2
        
        # 转换为像素坐标
        y_pixel = (gaze_points_2d[:, 0] * H).long()  # (B,)
        x_pixel = (gaze_points_2d[:, 1] * W).long()  # (B,)
        
        local_regions = []
        
        for b in range(batch_size):
            y_center = y_pixel[b].item()
            x_center = x_pixel[b].item()
            
            # 计算区域边界
            y_start = max(0, y_center - half_size)
            y_end = min(H, y_center + half_size)
            x_start = max(0, x_center - half_size)
            x_end = min(W, x_center + half_size)
            
            # 提取区域（考虑边界）
            if x_end - x_start == self.region_size and y_end - y_start == self.region_size:
                # 正常情况：直接提取
                local_region = images[b:b+1, :, y_start:y_end, x_start:x_end]
            else:
                # 边界情况：使用grid_sample
                # 创建采样网格
                y_coords = torch.arange(
                    y_center - half_size,
                    y_center + half_size,
                    dtype=torch.float32
                ).clamp(0, H - 1)
                
                x_coords = torch.arange(
                    x_center - half_size,
                    x_center + half_size,
                    dtype=torch.float32
                )
                
                # 处理360度图像的左右边界连续性
                x_coords = (x_coords + W) % W  # wrap around
                
                # 创建归一化坐标网格 [-1, 1]
                y_grid, x_grid = torch.meshgrid(y_coords, x_coords, indexing='ij')
                y_grid_norm = (y_grid / H) * 2 - 1
                x_grid_norm = (x_grid / W) * 2 - 1
                
                # 组合成grid_sample需要的格式
                grid = torch.stack([x_grid_norm, y_grid_norm], dim=-1).unsqueeze(0)
                grid = grid.to(images.device)
                
                # 提取局部区域
                local_region = F.grid_sample(
                    images[b:b+1],  # (1, 3, H, W)
                    grid,  # (1, region_size, region_size, 2)
                    mode='bilinear',
                    align_corners=True
                )  # (1, 3, region_size, region_size)
            
            local_regions.append(local_region.squeeze(0))
        
        return torch.stack(local_regions, dim=0)  # (B, 3, region_size, region_size)
```

**关键点**：
- 处理左右边界wrap：`x_coords = (x_coords + W) % W`
- 使用`grid_sample`处理边界情况

class AdaptiveDMM(DMM):

    自适应深度马尔可夫模型
    
    主要修改：
    1. 替换CNN为AdaptiveSphere_CNN
    2. 修改model()方法，支持动态特征提取
    3. 在循环中根据注视点提取局部特征

#### 详细修改

```python
class AdaptiveDMM(DMM):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        
        # 替换为自适应CNN
        self.cnn = AdaptiveSphere_CNN(out_put_dim=self.z_dim)
        
        # 注视次数计数器（用于决定何时切换粗细）
        self.coarse_threshold = 5  # 前5步使用粗特征
    
    def model(self, scanpaths, scanpaths_reversed, mask, scanpath_lengths, 
              images=None, annealing_factor=1.0, predict=False):
        T_max = scanpaths.size(1)
        pyro.module("dmm", self)
        
        # ===== 步骤1：初始化隐状态（保持不变）=====
        z_prev = self.z_0.expand(scanpaths.size(0), self.z_0.size(0))
        z_prev = self.tanh(self.twoZ_to_z_dim(
            torch.cat((z_prev, self.tanh(self.input_to_z_dim(scanpaths[:, 0, :]))), dim=1)
        ))
        
        # ===== 步骤2：提取粗特征（Glance阶段）=====
        s_coarse = self.cnn(images, mode='coarse')  # (B, 50)
        
        # ===== 步骤3：序列生成循环（关键修改）=====
        with pyro.plate("z_minibatch", len(scanpaths)):
            for t in pyro.markov(range(1, T_max + 1)):
                
                # ===== 3.1 决定使用粗特征还是细特征 =====
                if t <= self.coarse_threshold:
                    # 粗粒度阶段：使用全局粗特征
                    current_img_features = F.pad(s_coarse, (0, 50))  # (B, 100)
                else:
                    # 细粒度阶段：根据当前注视点提取局部特征
                    # 获取上一个注视点（用于提取局部区域）
                    if t == 1:
                        # 第一个时间步：使用初始注视点
                        prev_gaze_2d = xyz2plane(scanpaths[:, 0, :])  # (B, 2)
                    else:
                        # 后续时间步：使用上一个生成的注视点
                        prev_gaze_2d = xyz2plane(x_t_prev)  # (B, 2)
                    
                    # 提取局部细特征并融合
                    current_img_features = self.cnn(
                        images,
                        gaze_points=prev_gaze_2d,
                        mode='fine'
                    )  # (B, 100)
                
                # ===== 3.2 状态转移（使用动态特征）=====
                z_mu, z_sigma = self.trans(z_prev, current_img_features)
                #                                    ↑
                #                              每个t不同
                
                # ===== 3.3 采样隐状态（保持不变）=====
                with poutine.scale(scale=annealing_factor):
                    z_t = pyro.sample("z_%d" % t, dist.Normal(z_mu, z_sigma)
                                      .mask(mask[:, t - 1: t]).to_event(1))
                
                # ===== 3.4 生成注视点（保持不变）=====
                x_mu, x_sigma = self.emitter(z_t)
                
                if not predict:
                    pyro.sample("obs_x_%d" % t, dist.Normal(x_mu, x_sigma)
                                .mask(mask[:, t - 1: t]).to_event(1),
                                obs=scanpaths[:, t - 1, :])
                else:
                    x_t = pyro.sample("obs_x_%d" % t, dist.Normal(x_mu, x_sigma)
                                      .mask(mask[:, t - 1: t]).to_event(1))
                    x_t_prev = x_t  # 保存用于下一步
                
                z_prev = z_t
```

**关键修改点**：
1. ✅ 初始提取粗特征`s_coarse`
2. ✅ 循环中根据时间步决定使用粗特征还是细特征
3. ✅ 细特征阶段：根据注视点提取局部区域并融合
4. ✅ 状态转移使用动态的`current_img_features`

class FeatureFusion(nn.Module):
    """特征融合：融合粗特征和细特征"""
    def __init__(self, z_dim=100):
        super().__init__()
        self.fusion = nn.Sequential(
            nn.Linear(z_dim, z_dim),
            nn.ReLU(),
            nn.Linear(z_dim, z_dim)
        )
    
    def forward(self, s_coarse, s_fine):
        combined = torch.cat([s_coarse, s_fine], dim=1)  # (B, 100)
        return self.fusion(combined)  # (B, 100)

class AdaptiveSphere_CNN(nn.Module):
    """自适应球面CNN"""
    def __init__(self, z_dim=100, region_size=64):
        super().__init__()
        self.z_dim = z_dim
        self.coarse_cnn = Sphere_CNN(out_put_dim=z_dim // 2)  # 50维
        self.fine_cnn = Sphere_CNN(out_put_dim=z_dim // 2)  # 50维
        self.region_extractor = RegionExtractor(region_size)
        self.feature_fusion = FeatureFusion(z_dim)
    
    def forward(self, images, gaze_points=None, mode='coarse'):
        if mode == 'coarse':
            return self.coarse_cnn(images)  # (B, 50)
        elif mode == 'fine' and gaze_points is not None:
            local_patches = self.region_extractor(images, gaze_points)
            s_fine = self.fine_cnn(local_patches)  # (B, 50)
            s_coarse = self.coarse_cnn(images)  # (B, 50)
            return self.feature_fusion(s_coarse, s_fine)  # (B, 100)
