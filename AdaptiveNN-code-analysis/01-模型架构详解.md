# 01 - 模型架构详解

本文件详细解析 `dynamic_deitS` 模型的架构设计。

---

## 📦 模型类定义

### 核心类: `dynamic_deitS`

```python
class dynamic_deitS(nn.Module):
    def __init__(
        self,
        seq_len,                    # 序列长度（注视次数）
        feature_in_chans,           # 特征通道数（384）
        recover_n,                  # 恢复机制的邻域大小
        remaining_blocks,           # Glance Net 中用于分类的剩余块数
        glance_input_size,          # Glance Net 输入尺寸（112）
        glance_net_depth,           # Glance Net 深度（12）
        glance_net_mlp_ratio,       # MLP 扩展比例（4）
        glance_net_drop_path,       # Drop path 比率
        focus_patch_size,           # Focus Net patch 尺寸（112）
        focus_net_reg_size,         # Focus Net 正则化尺寸
        focus_net_depth,            # Focus Net 深度（12）
        focus_net_mlp_ratio,        # MLP 扩展比例（4）
        focus_net_drop_path,        # Drop path 比率
        multi_cls_drop_path,        # 多分类头的 drop path
        policy_net_hidden_chans,    # 策略网络隐藏层通道数
        policy_net_kernel_size,     # 策略网络卷积核大小
        **kwargs
    ):
```

## 🏗️ 模型组件初始化

### 1. **Glance Net (全局浏览网络)**

```python
# 配置 Glance Net 参数
glance_net_kwargs = kwargs.copy()
glance_net_kwargs['depth'] = self.glance_net_depth        # 12层
glance_net_kwargs['mlp_ratio'] = self.glance_net_mlp_ratio  # 4
glance_net_kwargs['drop_path_rate'] = self.glance_net_drop_path
glance_net_kwargs['img_size'] = self.glance_input_size     # 112

# 创建 Glance Net (基于 DeiT-Small)
self.glance_net = deit_small_patch16_224(**glance_net_kwargs)
```

**功能**:
- 输入: 112×112 图像
- 输出: 全局特征图 (7×7×384)，因为 112÷16=7
- 作用: 快速理解整张图像的全局信息

---

### 2. **Focus Net (局部聚焦网络)**

```python
# 配置 Focus Net 参数
kwargs['depth'] = self.focus_net_depth          # 12层
kwargs['mlp_ratio'] = self.focus_net_mlp_ratio  # 4
kwargs['drop_path_rate'] = self.focus_net_drop_path
kwargs['img_size'] = self.focus_patch_size      # 112

# 创建 Focus Net
self.focus_net = deit_small_patch16_224(**kwargs)
```

**功能**:
- 输入: 112×112 的图像 patch
- 输出: 局部特征 (7×7×384)
- 作用: 对选定区域进行精细分析

---

### 3. **分类头组件**

```python
# 每个注视步骤后都有一个分类头
self.policy_net_classifier_list = nn.ModuleList([
    nn.Sequential(*[
        self.glance_net.partial_create_block_func(drop_path=self.multi_cls_drop_path)
        for __ in range(remaining_blocks)  # 4个 Transformer 块
    ])
    for _ in range(seq_len)  # seq_len 个步骤（4个）
])

# 归一化层
self.policy_net_norm = nn.ModuleList([
    partial(nn.LayerNorm, eps=1e-6)(self.glance_net.num_features)  # 384
    for _ in range(seq_len + 1)  # 1个初始 + seq_len 个步骤
])

# 分类头
self.policy_net_head = nn.ModuleList([
    nn.Linear(self.glance_net.num_features, self.glance_net.num_classes)  # 384 -> 1000
    for _ in range(seq_len + 1)
])
```

**说明**:
- 初始分类头: 基于 Glance Net 的初步分类结果
- 后续分类头: 每个 Focus 步骤后的分类结果
- 所有分类头共享相同的 Glance Net backbone

---

### 4. **策略网络 (Policy Network)**

策略网络用于决定下一个注视点的位置，包含两个部分：

#### 4.1 动作网络 (Action Network)

```python
self.policy_net_patch = policy_net_patch(
    feature_in_chans=self.feature_in_chans,      # 384
    hidden_chans=policy_net_hidden_chans,        # 128
    kernel_size=policy_net_kernel_size,          # 3
    feature_size=self.glance_feature_size,       # 7 (112÷16)
    seq_len=self.seq_len,                        # 4
    is_policy_net=True                           # 输出2维 (x, y)
)
```

**输出**: 归一化的位置坐标 `[x, y]` ∈ [0, 1]

#### 4.2 价值网络 (Value Network)

```python
self.policy_net_patch_stateV = policy_net_patch(
    feature_in_chans=self.feature_in_chans,
    hidden_chans=policy_net_hidden_chans,
    kernel_size=policy_net_kernel_size,
    feature_size=self.glance_feature_size,
    seq_len=self.seq_len,
    is_policy_net=False                          # 输出1维 (state value)
)
```

**输出**: 状态价值标量（用于 PPO 训练）

### 5. **特征恢复机制 (Recovery Mechanism)**

特征恢复机制负责将局部特征融合回全局特征图：

```python
# 邻域偏移量（用于特征融合）
n = self.recover_n  # 5
offset_x = torch.arange(0, n) - (n - 1) // 2    # [-2, -1, 0, 1, 2]
offset_y = torch.arange(0, n) - (n - 1) // 2
offset_xy = torch.stack(torch.meshgrid([offset_x, offset_y], indexing='xy'))
# 形状: (2, 5, 5) -> (1, 2, 1, 1, 25)
self.register_buffer("offset_xy", offset_xy)
```

**恢复网络组件**:

```python
# 特征复用归一化
self.policy_net_recover_reuseNorm_list = nn.ModuleList([
    partial(nn.LayerNorm, eps=1e-6)(self.feature_in_chans)
    for _ in range(seq_len)
])

# 特征复用卷积头
self.policy_net_recover_reuseConvHead = nn.Conv2d(
    in_channels=self.feature_in_chans,  # 384
    out_channels=self.feature_in_chans,  # 384
    kernel_size=7, stride=1, padding=3,
    groups=self.feature_in_chans,       # 深度可分离卷积
    bias=False
)

# 特征复用 MLP
self.policy_net_recover_reuseMLP = Mlp(
    in_features=self.feature_in_chans,      # 384
    hidden_features=self.feature_in_chans * 4,  # 1536
    act_layer=nn.GELU,
    drop=0.
)

# 恢复权重生成网络
self.policy_net_recover = Mlp(
    in_features=self.feature_in_chans,      # 384
    hidden_features=self.feature_in_chans * 4,  # 1536
    out_features=self.recover_n ** 2,       # 25 (5×5)
    act_layer=nn.GELU,
    drop=0.
)
```

## 🔍 Policy_Net_Patch 详解

策略网络的核心组件，用于从特征图生成动作或价值：

```python
class policy_net_patch(nn.Module):
    def __init__(
        self, 
        feature_in_chans,    # 384
        hidden_chans=128,    # 隐藏层通道数
        kernel_size=7,       # 卷积核大小
        feature_size=7,      # 特征图尺寸 (7×7)
        seq_len=4,           # 序列长度
        is_policy_net=True   # True=动作网络, False=价值网络
    ):
```

**网络结构**:

```
输入: (B, 384, 7, 7) 特征图
  ↓
[深度可分离卷积] kernel_size×kernel_size, groups=384
  ↓ (B, 384, 7, 7)
[GELU 激活]
  ↓
[1×1 卷积] 384 → 128
  ↓ (B, 128, 7, 7)
[GELU 激活]
  ↓
[Flatten] → (B, 128×7×7) = (B, 6272)
  ↓
[Linear] 6272 → 1024
  ↓
[LayerNorm]
  ↓
[GELU]
  ↓
[Linear] 1024 → 512
  ↓
[LayerNorm]
  ↓
[GELU]
  ↓
输出头:
  - 如果是策略网络: Linear(512 → 2) + Sigmoid → (B, 2) [x, y坐标]
  - 如果是价值网络: Linear(512 → 1) → (B, 1) [状态价值]
```

**关键设计**:
- 每个步骤使用不同的 LayerNorm（`self.ln_list[step_index]`）
- 输出坐标经过 Sigmoid 归一化到 [0, 1]
- 价值网络不需要 Sigmoid，直接输出标量

## 📐 尺寸计算

### 特征图尺寸

- **Glance Net 输入**: 112×112
- **Patch size**: 16×16
- **特征图尺寸**: 112 ÷ 16 = **7×7**
- **特征通道数**: 384 (DeiT-Small)

### 特征维度流转

```
图像 (B, 3, 112, 112)
  ↓ Glance Net (前8层)
全局特征 (B, 49, 384)  # 49 = 7×7
  ↓ reshape
特征图 (B, 384, 7, 7)
  ↓ Policy Net
动作坐标 (B, 2)  # [x, y] ∈ [0, 1]
  ↓ 提取 patch
局部图像 (B, 3, 112, 112)
  ↓ Focus Net
局部特征 (B, 49, 384)
  ↓ Recovery
融合特征 (B, 49, 384)
  ↓ 分类头
分类结果 (B, 1000)
```

## 🎯 关键设计理念

1. **双网络架构**: 
   - Glance Net 快速全局理解
   - Focus Net 精细局部分析

2. **渐进式特征细化**:
   - 每一步都基于上一步的特征
   - 通过 Recovery 机制累积信息

3. **端到端可训练**:
   - 所有组件联合训练
   - 策略网络通过 PPO 优化

4. **计算效率**:
   - 只处理小尺寸输入 (112×112)
   - 动态选择关键区域
   - 避免处理高分辨率全图
