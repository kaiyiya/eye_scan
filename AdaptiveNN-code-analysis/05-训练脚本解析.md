## 🚀 2. 主函数 (main)

### 2.1 环境初始化

```python
def main(args):
    # 分布式训练初始化
    utils.init_distributed_mode(args)
    
    # 设置设备
    device = torch.device(args.device)
    
    # 设置随机种子
    seed = args.seed + utils.get_rank()
    torch.manual_seed(seed)
    np.random.seed(seed)
    cudnn.benchmark = True  # 加速训练
```

if args.finetune:
    checkpoint = torch.load(args.finetune, map_location='cpu')

    checkpoint_model = None
    for model_key in args.model_key.split('|'):  # 'model|module'

### 3.2 训练主循环

```python
max_accuracy = 0.0
max_accuracy_glance = 0.0

print("Start training for %d epochs" % args.epochs)
start_time = time.time()

for epoch in range(args.start_epoch, args.epochs):
    # 设置 epoch（用于分布式采样器）
    if args.distributed:
        data_loader_train.sampler.set_epoch(epoch)
    
    # 设置日志步数
    if log_writer is not None:
        log_writer.set_step(epoch * num_training_steps_per_epoch * args.update_freq)
    
    # 训练一个 epoch
    train_stats = train_one_epoch(
        model, criterion, data_loader_train, optimizer,
        device, epoch, loss_scaler, args.clip_grad, mixup_fn,
        log_writer=log_writer, wandb_logger=wandb_logger,
        start_steps=epoch * num_training_steps_per_epoch,
        lr_schedule_values=lr_schedule_values, 
        wd_schedule_values=wd_schedule_values,
        num_training_steps_per_epoch=num_training_steps_per_epoch, 
        update_freq=args.update_freq, 
        args=args
    )
    
    # 保存检查点
    if args.output_dir and args.save_ckpt:
        if (epoch + 1) % args.save_ckpt_freq == 0 or epoch + 1 == args.epochs:
            utils.save_model(
                args=args, 
                model=model, 
                model_without_ddp=model_without_ddp, 
                optimizer=optimizer,
                loss_scaler=loss_scaler, 
                epoch=epoch
            )
    
    # 验证
    if data_loader_val is not None:
        test_stats = evaluate(data_loader_val, model, device, args=args)
        print(f"Accuracy: {test_stats['acc1']:.1f}%")
        
        # 保存最佳模型
        if max_accuracy < test_stats["acc1"]:
            max_accuracy = test_stats["acc1"]
            if args.output_dir and args.save_ckpt:
                utils.save_model(
                    args=args, 
                    model=model, 
                    model_without_ddp=model_without_ddp, 
                    optimizer=optimizer,
                    loss_scaler=loss_scaler, 
                    epoch="best"
                )
        
        print(f'Max accuracy: {max_accuracy:.2f}%')
        print(f"Glance Accuracy: {test_stats['acc1_glance']:.1f}%")
        
        if max_accuracy_glance < test_stats["acc1_glance"]:
            max_accuracy_glance = test_stats["acc1_glance"]
        print(f'Glance Max accuracy: {max_accuracy_glance:.2f}%')
    
    # 记录日志
    log_stats = {
        **{f'train_{k}': v for k, v in train_stats.items()},
        **{f'test_{k}': v for k, v in test_stats.items()},
        'epoch': epoch,
        'n_parameters': n_parameters
    }
    
    if args.output_dir and utils.is_main_process():
        with open(os.path.join(args.output_dir, "log.txt"), "a") as f:
            f.write(json.dumps(log_stats) + "\n")

total_time = time.time() - start_time
print('Training time {}'.format(str(datetime.timedelta(seconds=int(total_time)))))
```

## 🎯 关键配置说明

1. **batch_size**: 每个 GPU 的批次大小，总批次 = batch_size × GPU数 × update_freq

2. **seq_l**: 注视序列长度，决定模型进行几次局部观察

3. **update_policy_freq**: 策略网络更新频率，值越大更新越稳定但训练越慢

4. **ppo_update_steps**: 每次 PPO 更新的步数，通常 2-5 步

5. **gamma**: 折扣因子，影响长期奖励的权重

6. **loss_reg_focus_net_weight**: Focus Net 正则化损失的权重

---

## 📝 总结

训练脚本的核心流程：

1. **初始化**: 环境、数据、模型
2. **训练循环**: 
   - 监督学习更新 Glance/Focus 网络
   - 定期使用 PPO 更新策略网络
3. **验证**: 定期评估模型性能
4. **保存**: 保存检查点和最佳模型

整个过程支持分布式训练、混合精度、梯度累积等高级特性。
