# 流程图对比：ScanDMM vs AdaptiveScanDMM

## 📊 原始 ScanDMM 流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                    原始 ScanDMM 完整流程                         │
└─────────────────────────────────────────────────────────────────┘

输入：360度图像 I
(B, 3, 128, 256)
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤1：图像特征提取（一次性，固定）                          │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  Sphere_CNN                                          │  │
│  │  输入: (B, 3, 128, 256)                              │  │
│  │  处理: 全图CNN前向传播                                │  │
│  │  输出: img_features (B, 100)                         │  │
│  │  计算成本: 100%                                       │  │
│  │  时间: T0（只计算一次）                               │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤2：状态初始化                                            │
│  z_0 = F(z_0, x_1)                                          │
│  输出: z_prev (B, 100)                                       │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤3：序列生成循环（固定长度 T_max=20）                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  for t in range(1, T_max + 1):                     │   │
│  │                                                      │   │
│  │    ┌────────────────────────────────────────────┐  │   │
│  │    │ 步骤3.1: 状态转移                           │  │   │
│  │    │ z_t ~ GatedTransition(z_{t-1}, img_features)│  │   │
│  │    │          ↑              ↑                    │  │   │
│  │    │      上一步状态      固定特征                │  │   │
│  │    │                      (所有t相同)            │  │   │
│  │    └────────────────────────────────────────────┘  │   │
│  │    │                                                │   │
│  │    ▼                                                │   │
│  │    ┌────────────────────────────────────────────┐  │   │
│  │    │ 步骤3.2: 采样隐状态                         │  │   │
│  │    │ z_t ~ Normal(z_mu, z_sigma)                 │  │   │
│  │    └────────────────────────────────────────────┘  │   │
│  │    │                                                │   │
│  │    ▼                                                │   │
│  │    ┌────────────────────────────────────────────┐  │   │
│  │    │ 步骤3.3: 生成注视点                         │  │   │
│  │    │ x_t ~ Emitter(z_t)                         │  │   │
│  │    │ 输出: (x, y, z) 3D坐标                      │  │   │
│  │    └────────────────────────────────────────────┘  │   │
│  │    │                                                │   │
│  │    ▼                                                │   │
│  │    z_prev = z_t  (更新状态)                        │   │
│  │                                                      │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
输出：扫描路径序列
x_1, x_2, ..., x_20

关键问题：
❌ img_features在所有时间步都是相同的
❌ 无法根据注视点动态调整
❌ 计算成本固定（100%）
```

## 🟢 改进后 AdaptiveScanDMM 流程图

```
┌─────────────────────────────────────────────────────────────────┐
│              AdaptiveScanDMM 完整流程（多尺度动态）              │
└─────────────────────────────────────────────────────────────────┘

输入：360度图像 I
(B, 3, 128, 256)
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤1：Glance阶段 - 快速提取粗特征（一次性）                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  粗粒度CNN (降采样或轻量级)                           │  │
│  │  输入: (B, 3, 128, 256)                               │  │
│  │  处理: 降采样到(B, 3, 64, 128) + 轻量级CNN            │  │
│  │  输出: s_coarse (B, 50)                               │  │
│  │  计算成本: ~30%                                        │  │
│  │  时间: T0（只计算一次）                                │  │
│  │  特点: 所有时间步复用                                  │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤2：状态初始化（保持不变）                                │
│  z_0 = F(z_0, x_1)                                          │
│  输出: z_prev (B, 100)                                       │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤3：序列生成循环（动态特征提取）                           │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  for t in range(1, T_max + 1):                     │   │
│  │                                                      │   │
│  │    ┌────────────────────────────────────────────┐  │   │
│  │    │ 判断：使用粗特征还是细特征？                 │  │   │
│  │    │ if t <= coarse_threshold (例如5):           │  │   │
│  │    │   使用粗特征                                  │  │   │
│  │    │ else:                                       │  │   │
│  │    │   提取细特征                                  │  │   │
│  │    └────────────────────────────────────────────┘  │   │
│  │    │                                                │   │
│  │    ├─────────────── 粗特征路径 ────────────────┤   │   │
│  │    │                                                │   │
│  │    │  ┌──────────────────────────────────────┐ │   │   │
│  │    │  │ 步骤3.1a: 使用粗特征                  │ │   │   │
│  │    │  │ current_features = Pad(s_coarse)       │ │   │   │
│  │    │  │ 输出: (B, 100)                        │ │   │   │
│  │    │  │ 计算成本: 0%（已预计算）               │ │   │   │
│  │    │  └──────────────────────────────────────┘ │   │   │
│  │    │                                                │   │
│  │    └─────────────── 细特征路径 ────────────────┤   │   │
│  │    │                                                │   │
│  │    │  ┌──────────────────────────────────────┐ │   │   │
│  │    │  │ 步骤3.1b.1: 获取注视点                │ │   │   │
│  │    │  │ prev_gaze = x_{t-1} 或 scanpaths[0]   │ │   │   │
│  │    │  │ 输出: (B, 2) 归一化坐标                │ │   │   │
│  │    │  └──────────────────────────────────────┘ │   │   │
│  │    │    │                                        │   │   │
│  │    │    ▼                                        │   │   │
│  │    │  ┌──────────────────────────────────────┐ │   │   │
│  │    │  │ 步骤3.1b.2: 提取局部区域              │ │   │   │
│  │    │  │ RegionExtractor(images, prev_gaze)   │ │   │   │
│  │    │  │ 输入: (B, 3, 128, 256), (B, 2)        │ │   │   │
│  │    │  │ 处理: 根据注视点提取64×64局部区域      │ │   │   │
│  │    │  │ 输出: local_patches (B, 3, 64, 64)    │ │   │   │
│  │    │  │ 计算成本: ~5%                         │ │   │   │
│  │    │  └──────────────────────────────────────┘ │   │   │
│  │    │    │                                        │   │   │
│  │    │    ▼                                        │   │   │
│  │    │  ┌──────────────────────────────────────┐ │   │   │
│  │    │  │ 步骤3.1b.3: Focus阶段 - 提取细特征   │ │   │   │
│  │    │  │ 细粒度CNN(local_patches)              │ │   │   │
│  │    │  │ 输入: (B, 3, 64, 64)                  │ │   │   │
│  │    │  │ 处理: Sphere_CNN（但输入更小）         │ │   │   │
│  │    │  │ 输出: s_fine (B, 50)                   │ │   │   │
│  │    │  │ 计算成本: ~20%（仅局部区域）           │ │   │   │
│  │    │  └──────────────────────────────────────┘ │   │   │
│  │    │    │                                        │   │   │
│  │    │    ▼                                        │   │   │
│  │    │  ┌──────────────────────────────────────┐ │   │   │
│  │    │  │ 步骤3.1b.4: 特征融合                  │ │   │   │
│  │    │  │ FeatureFusion(s_coarse, s_fine)       │ │   │   │
│  │    │  │ 输入: (B, 50), (B, 50)                │ │   │   │
│  │    │  │ 处理: 拼接或学习融合                   │ │   │   │
│  │    │  │ 输出: current_features (B, 100)        │ │   │   │
│  │    │  └──────────────────────────────────────┘ │   │   │
│  │    │                                                │   │
│  │    └───────────────────────────────────────────────┘   │
│  │    │                                                │   │
│  │    ▼                                                │   │
│  │    ┌────────────────────────────────────────────┐  │   │
│  │    │ 步骤3.2: 状态转移（使用动态特征）            │  │   │
│  │    │ z_t ~ GatedTransition(z_{t-1}, current_features)││   │
│  │    │          ↑              ↑                    │  │   │
│  │    │      上一步状态      动态特征                │  │   │
│  │    │                     (每个t不同)              │  │   │
│  │    └────────────────────────────────────────────┘  │   │
│  │    │                                                │   │
│  │    ▼                                                │   │
│  │    ┌────────────────────────────────────────────┐  │   │
│  │    │ 步骤3.3: 采样隐状态                         │  │   │
│  │    │ z_t ~ Normal(z_mu, z_sigma)                │  │   │
│  │    └────────────────────────────────────────────┘  │   │
│  │    │                                                │   │
│  │    ▼                                                │   │
│  │    ┌────────────────────────────────────────────┐  │   │
│  │    │ 步骤3.4: 生成注视点                          │  │   │
│  │    │ x_t ~ Emitter(z_t)                          │  │   │
│  │    │ 输出: (x, y, z) 3D坐标                      │  │   │
│  │    └────────────────────────────────────────────┘  │   │
│  │    │                                                │   │
│  │    ▼                                                │   │
│  │    z_prev = z_t, x_t_prev = x_t  (更新状态)        │   │
│  │                                                      │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
输出：扫描路径序列
x_1, x_2, ..., x_T (T ≤ T_max)

关键改进：
✅ 初始阶段使用粗特征（快速，30%成本）
✅ 后续阶段根据注视点动态提取细特征（20%成本/步）
✅ 每个时间步使用不同的特征（从粗到细）
✅ 提供全局上下文+局部细节的丰富信息
```


## 🔍 详细步骤对比表

| 步骤 | 原始ScanDMM | AdaptiveScanDMM | 关键差异 |
|------|------------|----------------|---------|
| **初始特征提取** | Sphere_CNN<br/>输入: (B,3,128,256)<br/>输出: (B,100)<br/>成本: 100%<br/>时间: T0 | 粗CNN<br/>输入: (B,3,128,256)或降采样<br/>输出: (B,50)<br/>成本: 30%<br/>时间: T0 | ✅ 成本降低70%<br/>✅ 输出维度减半 |
| **t=1状态转移** | GatedTransition(z_0, img_features)<br/>img_features: (B,100)固定 | GatedTransition(z_0, current_features)<br/>current_features: (B,100)<br/>来源: Pad(s_coarse) | ✅ 使用粗特征<br/>✅ 快速 |

| **t=6状态转移** | GatedTransition(z_5, img_features)<br/>img_features: (B,100)固定 | 1. Extract(I, x_5) → patch<br/>2. FineCNN(patch) → s_fine<br/>3. Fusion(s_coarse, s_fine) → s<br/>4. GatedTransition(z_5, s)<br/>s: (B,100)动态 | ✅ 提取局部区域<br/>✅ 提取细特征<br/>✅ 特征融合<br/>✅ 使用动态特征 |

## 💡 核心改进可视化

### 特征使用模式对比

```
原始 ScanDMM:
时间步:  1    2    3    4    5    6    ...   20
特征:   [s]  [s]  [s]  [s]  [s]  [s]  ...   [s]
        ↑    ↑    ↑    ↑    ↑    ↑          ↑
        所有时间步使用相同的特征s

改进后 AdaptiveScanDMM:
时间步:  1    2    3    4    5    6    7    ...   20
特征:   [s_c][s_c][s_c][s_c][s_c][s_1][s_2] ...   [s_15]
        ↑    ↑    ↑    ↑    ↑    ↑    ↑           ↑
        粗特征    粗特征    融合特征（每个t不同）
        (快速)   (快速)   (全局+局部)
```

## 📐 数据流维度对比

### 原始 ScanDMM 维度流转

```
输入: (B, 3, 128, 256)
    ↓ [Sphere_CNN]
特征: (B, 100)  ← 固定
    ↓ [循环中]
    ├─→ z_t: (B, 100)
    └─→ x_t: (B, 3)
```

### 改进后 AdaptiveScanDMM 维度流转

```
输入: (B, 3, 128, 256)
    ↓ [粗CNN]
粗特征: (B, 50)  ← 固定，复用
    ↓
┌─────────────────────────────────────┐
│ 循环中:                              │
│  t <= 5:                            │
│    粗特征 (B, 50) → Pad → (B, 100)   │
│                                     │
│  t > 5:                             │
│    输入 (B, 3, 128, 256)            │
│    + 注视点 (B, 2)                  │
│    ↓ [提取局部]                      │
│    局部patch: (B, 3, 64, 64)        │
│    ↓ [细CNN]                         │
│    细特征: (B, 50)                  │
│    ↓ [融合]                          │
│    粗特征 (B, 50) + 细特征 (B, 50)  │
│    → 融合特征 (B, 100)               │
└─────────────────────────────────────┘
    ↓
    ├─→ z_t: (B, 100)
    └─→ x_t: (B, 3)
```
