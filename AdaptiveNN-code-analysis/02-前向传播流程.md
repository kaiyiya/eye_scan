# 02 - 前向传播流程详解

本文件详细解析 `forward_backbone` 函数的执行流程，这是模型的核心推理过程。

---

## 🎬 函数入口

```python
def forward_backbone(self, imgs, seq_l=4, ppo_std_this_iter=None):
    """
    参数:
        imgs: 输入图像 (B, 3, H, W)，例如 (B, 3, 288, 288)
        seq_l: 注视序列长度，默认 4
        ppo_std_this_iter: PPO 训练时的动作噪声标准差
    """
```

---

## 📦 输出字典初始化

```python
expected_outputs = {
    'x_glance': [],           # Glance 阶段的分类结果
    'x_focus': [],            # 每个 Focus 步骤后的分类结果列表
    'actions': [],            # 每个步骤选择的注视点位置
    'actions_logprobs': [],   # 动作的对数概率（用于 PPO）
    '_state_values': [],      # 状态价值（用于 PPO）
    'states': [],             # 每个步骤的状态特征
    'pos_std': [],            # 动作位置的标准差
    'pos_mean': [],           # 动作位置的平均值
    'outputs_reg_focus_net': None,  # Focus Net 的正则化输出
}
```

---

## 🔍 阶段 1: 正则化输出（辅助训练）

```python
expected_outputs['outputs_reg_focus_net'] = self.infer_focus_net_only(imgs)
```

**作用**: 
- 对整张图像进行 Focus Net 处理（下采样到 focus_net_reg_size）
- 用于辅助训练，提供额外的监督信号
- 仅用于损失计算，不影响主流程

---

## 👁️ 阶段 2: Glance 阶段（全局浏览）

### 2.1 图像下采样

```python
x = torch.nn.functional.interpolate(
    imgs, 
    size=(self.glance_input_size, self.glance_input_size),  # (112, 112)
    mode='bicubic'
)
# 输入: (B, 3, 288, 288) → 输出: (B, 3, 112, 112)
```

**目的**: 将输入图像下采样到小尺寸，快速获取全局信息

### 2.2 Glance Net 特征提取（前半部分）

```python
global_features = self.glance_net(x, remaining_blocks=self.remaining_blocks)
# 输入: (B, 3, 112, 112)
# 输出: (B, 49, 384)  # 49 = 7×7, 384 = 特征维度
```

**说明**:
- `remaining_blocks=4` 表示只使用前 `12-4=8` 层 Transformer
- 输出全局特征图：7×7 的空间位置，每个位置 384 维特征

### 2.3 初步分类结果

```python
# 使用 Glance Net 的剩余层 (后4层)
x_glance = self.glance_net(global_features, remaining_blocks=-self.remaining_blocks)
# 输出: (B, 49, 384)

# 归一化
x_glance = self.policy_net_norm[0](x_glance)  # (B, 49, 384)

# 全局平均池化
x_glance = self.policy_net_avgpool(x_glance.transpose(1, 2))  # (B, 384, 1)
x_glance = torch.flatten(x_glance, 1)  # (B, 384)

# 分类头
x_glance = self.policy_net_pre_logits(x_glance)  # (B, 384)
x_glance = self.policy_net_head[0](x_glance)     # (B, 1000)

expected_outputs['x_glance'].append(x_glance)
```

**结果**: 获得基于全局快速浏览的初步分类结果

---

## 🔄 阶段 3: Focus 循环（局部聚焦）

```python
updated_features = global_features  # (B, 49, 384)
for focus_step_index in range(seq_l):  # 循环 4 次
    # ... 每个步骤的处理
```

### 步骤 3.1: 获取当前状态并保存

```python
B, L, C = updated_features.shape  # B=batch, L=49, C=384

# 保存当前状态（用于 PPO 训练）
expected_outputs['states'].append(updated_features.detach())  # (B, 49, 384)
```

### 步骤 3.2: 策略网络预测（选择注视点）

```python
# 将特征 reshape 为图像格式
# (B, 49, 384) → (B, 384, 7, 7)
feature_map = updated_features.detach().permute(0, 2, 1).reshape(B, C, 7, 7)

# 价值网络：评估当前状态的价值
_state_values = self.policy_net_patch_stateV(
    self.policy_net_patch_norm_list_stateV[focus_step_index](feature_map),
    focus_step_index
)  # 输出: (B, 1)

# 动作网络：预测下一个注视点位置
_actions = self.policy_net_patch(
    self.policy_net_patch_norm_list[focus_step_index](feature_map),
    focus_step_index
)  # 输出: (B, 2) - [x, y] 坐标，范围 [0, 1]
```

**说明**:
- `_actions` 是策略网络的原始输出（Sigmoid 后）
- 训练时需要添加噪声进行探索

### 步骤 3.3: 动作采样（训练时）

```python
if self.training:
    actions = _actions.float()  # (B, 2)
    
    # 创建多元高斯分布（添加探索噪声）
    action_var = torch.full((2,), ppo_std_this_iter, device=...)  # 例如 [0.1, 0.1]
    cov_mat = torch.diag(action_var)
    dist = torch.distributions.multivariate_normal.MultivariateNormal(
        actions, scale_tril=cov_mat
    )
    
    # 采样动作
    actions = dist.sample()  # (B, 2)
    actions = torch.clamp(actions, min=0, max=1)  # 限制在 [0, 1]
    
    # 计算对数概率（用于 PPO）
    actions_logprobs = dist.log_prob(actions)  # (B,)
else:
    # 推理时直接使用预测值（不添加噪声）
    actions_logprobs = torch.ones(B, device=...)
    actions = _actions  # 直接使用预测值
```

**关键点**:
- 训练时添加噪声以进行探索
- 推理时使用确定性策略（无噪声）

### 步骤 3.4: 提取图像 Patch

```python
actions = actions.detach()  # 断开梯度
expected_outputs['actions'].append(actions.detach())

# 添加缩放维度（这里固定为1，表示不缩放）
actions = torch.cat([actions, torch.ones_like(actions)], dim=1)  # (B, 4)

# 从原图中提取 patch
x_patch, reuse_feat_grid, grid = self.get_img_patches(
    imgs,                      # 原始图像 (B, 3, 288, 288)
    actions,                   # 动作 (B, 4) - [x, y, scale_x, scale_y]
    self.focus_patch_size,     # 112
    imgs.shape[-1]             # 288 (原图尺寸)
)
# 返回:
#   x_patch: (B, 3, 112, 112) - 提取的图像 patch
#   reuse_feat_grid: 特征网格坐标
#   grid: 特征恢复用的网格坐标
```

**`get_img_patches` 函数的作用**:
1. 根据动作坐标计算 patch 在原图中的位置
2. 使用仿射变换提取 patch
3. 返回提取的图像和对应的特征网格坐标

### 步骤 3.5: 特征复用准备

```python
feat_to_reuse = self.policy_net_recover_reuseMLP(
    self.policy_net_recover_reuseMLP_preLN_list[focus_step_index](
        self.get_reuse_faet(
            input_faet=updated_features,      # (B, 49, 384)
            reuse_feat_grid=reuse_feat_grid,  # 特征网格坐标
            focus_step_index=focus_step_index
        )  # 输出: (B, 49, 384) - 从全局特征中提取的对应区域特征
    )
)  # 输出: (B, 49, 384) - 处理后的特征，作为 Focus Net 的上下文
```

**`get_reuse_faet` 函数的作用**:
- 从全局特征图中提取与 patch 对应的区域特征
- 使用双线性插值进行特征采样
- 为 Focus Net 提供全局上下文信息

### 步骤 3.6: Focus Net 处理局部 Patch

```python
local_features = self.focus_net(
    x_patch,                          # (B, 3, 112, 112)
    remaining_blocks=0,               # 使用所有层
    context_embed=feat_to_reuse       # (B, 49, 384) - 上下文特征
)
# 输出: (B, 49, 384) - 局部特征的精细表示
```

**说明**:
- Focus Net 处理局部 patch，提取精细特征
- `context_embed` 提供了全局上下文信息
- 输出与全局特征图相同尺寸 (7×7)

### 步骤 3.7: 特征恢复（融合回全局特征图）

这是最复杂的部分，将局部特征融合回全局特征图：

```python
# 3.7.1 生成恢复权重
recover_policy_weight = self.policy_net_recover(
    self.policy_net_recover_preLN_list[focus_step_index](local_features)
)  # 输出: (B, 49, 25) - 25 = recover_n^2 = 5×5
# 每个位置预测一个 5×5 的权重矩阵

# 3.7.2 计算邻居坐标索引
neighbor_coords_index, outlier_mask = self.window_neighbor_grid(
    B, 
    grid,                          # patch 在原图中的位置
    self.focus_feature_size,       # 7
    self.glance_feature_size       # 7
)
# 返回:
#   neighbor_coords_index: (B, 49, 25) - 每个局部位置对应的全局位置索引
#   outlier_mask: (B, 49, 25) - 掩码，标记是否超出边界

# 3.7.3 应用掩码
recover_policy_weight = recover_policy_weight * outlier_mask

# 3.7.4 构建相对位置权重矩阵
relative_position_weight = torch.zeros(
    (B, 49, 49),  # (B, 局部位置数, 全局位置数)
    device=...
).scatter_add_(
    dim=2, 
    index=neighbor_coords_index,    # (B, 49, 25)
    src=recover_policy_weight       # (B, 49, 25)
).permute(0, 2, 1)  # (B, 49, 49)
# 结果: 每个全局位置包含来自局部特征的加权贡献

# 3.7.5 特征融合
updated_features = relative_position_weight @ local_features + updated_features
# (B, 49, 49) @ (B, 49, 384) = (B, 49, 384)
# 加上原始的全局特征
```

**恢复机制的直观理解**:
- 局部特征经过 Focus Net 处理后，需要"恢复"到全局特征图
- 使用空间注意力权重，将局部特征的每个位置分配到全局特征图的邻近位置
- 通过加权求和的方式融合局部和全局信息

### 步骤 3.8: 更新分类结果

```python
# 使用分类头网络（4个 Transformer 块）
x = self.policy_net_classifier_list[focus_step_index](updated_features)  # (B, 49, 384)

# 归一化
x = self.policy_net_norm[focus_step_index + 1](x)  # (B, 49, 384)

# 全局平均池化
x = self.policy_net_avgpool(x.transpose(1, 2))  # (B, 384, 1)
x = torch.flatten(x, 1)  # (B, 384)

# 分类
x = self.policy_net_pre_logits(x)  # (B, 384)
x = self.policy_net_head[focus_step_index + 1](x)  # (B, 1000)

expected_outputs['x_focus'].append(x)
```

**结果**: 每个 Focus 步骤后都会产生一个分类结果，逐步细化

## 📊 完整流程图

```
输入图像 (B, 3, 288, 288)
    ↓
[下采样] 112×112
    ↓
[Glance Net 前8层]
全局特征 (B, 49, 384)
    ↓
[Glance Net 后4层 + 分类头]
初步分类结果 x_glance (B, 1000)
    ↓
┌──────────────────────────────────────┐
│  Focus 循环 (seq_l=4次)              │
│                                      │
│  for step in [0, 1, 2, 3]:          │
│    ↓                                 │
│  1. Policy Net → 选择注视点 (x, y)   │
│    ↓                                 │
│  2. 提取 patch (112×112)             │
│    ↓                                 │
│  3. 特征复用 → 获取上下文特征         │
│    ↓                                 │
│  4. Focus Net → 提取局部特征          │
│    ↓                                 │
│  5. Recovery → 融合到全局特征        │
│    ↓                                 │
│  6. 分类头 → 更新分类结果             │
│                                      │
└──────────────────────────────────────┘
    ↓
最终分类结果 x_focus[-1] (B, 1000)
```

---

## 🎯 关键设计要点

1. **渐进式特征细化**: 
   - 每个步骤基于上一步的更新特征
   - 逐步累积局部信息到全局特征

2. **特征融合机制**:
   - Recovery 机制将局部特征加权融合回全局
   - 保持全局上下文的同时细化局部细节

3. **多步分类**:
   - 每一步都产生分类结果
   - 可以观察模型逐步优化的过程

4. **训练 vs 推理**:
   - 训练时添加噪声进行探索
   - 推理时使用确定性策略
