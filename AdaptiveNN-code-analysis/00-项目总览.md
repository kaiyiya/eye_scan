## 🎯 项目核心思想

AdaptiveNN 模拟人类视觉的**注视机制（Fixation Mechanism）**，通过以下步骤实现高效视觉感知：

```
输入图像
  ↓
[步骤1] Glance Net - 全局快速浏览 (112×112)
  ↓ 生成全局特征图
[步骤2] 策略网络 - 决定下一个注视点位置 (x, y)
  ↓ 提取局部 patch (112×112)
[步骤3] Focus Net - 精细处理局部区域
  ↓ 特征融合回全局特征图
[步骤4] 重复步骤2-3，共进行 seq_l 次 (默认4次)
  ↓
最终分类结果
```

---

## 🏗️ 核心架构组件

### 1. **Glance Net (全局浏览网络)**
- **作用**: 快速浏览整张图像，生成全局特征
- **输入**: 112×112 的小尺寸图像
- **架构**: DeiT-Small Vision Transformer
- **输出**: 全局特征图 (7×7 特征网格)

### 2. **Focus Net (局部聚焦网络)**
- **作用**: 对选定的局部区域进行精细处理
- **输入**: 112×112 的图像 patch
- **架构**: DeiT-Small Vision Transformer
- **输出**: 局部特征

### 3. **Policy Net (策略网络)**
- **作用**: 决定下一个注视点的位置 (x, y 坐标)
- **输入**: 当前全局特征图
- **输出**: 归一化的位置坐标 [0, 1]

### 4. **Recovery Mechanism (特征恢复机制)**
- **作用**: 将局部特征融合回全局特征图
- **方法**: 使用空间注意力权重进行加权融合

## 📊 数据流图

```
原始图像 (例如: 288×288)
    ↓ [下采样]
Glance 输入 (112×112)
    ↓ [Glance Net - 前8层]
全局特征 (7×7×384)
    ↓ [分类头]
初步分类结果 (x_glance)
    ↓
┌─────────────────────────────────┐
│  Focus 步骤循环 (seq_l=4次)      │
├─────────────────────────────────┤
│  1. Policy Net → 选择注视点 (x,y)│
│  2. 提取 patch (112×112)        │
│  3. Focus Net → 提取局部特征     │
│  4. Recovery → 融合到全局特征    │
│  5. 分类头 → 更新分类结果        │
└─────────────────────────────────┘
    ↓
最终分类结果 (x_focus[-1])
```

## 🔑 关键参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `seq_l` | 4 | 注视序列长度（进行几次局部观察）|
| `glance_input_size` | 112 | 全局网络的输入尺寸 |
| `focus_patch_size` | 112 | 局部 patch 的尺寸 |
| `glance_net_depth` | 12 | Glance Net 的 Transformer 层数 |
| `focus_net_depth` | 12 | Focus Net 的 Transformer 层数 |
| `remaining_blocks` | 4 | Glance Net 中用于分类的剩余层数 |
| `recover_n` | 5 | 特征恢复时考虑的邻居网格大小 |

## 🎓 核心技术点

### 1. **自适应注意力机制**
- 模型不需要处理整张高分辨率图像
- 根据任务需要动态选择关键区域
- 可以节省大量计算资源

### 2. **强化学习训练 (PPO)**
- 使用 PPO (Proximal Policy Optimization) 训练策略网络
- 不需要标注注视点位置（无监督学习）
- 通过分类准确率提升作为奖励信号

### 3. **特征融合策略**
- 将局部特征加权融合回全局特征图
- 保持全局上下文信息
- 逐步细化特征表示
