# 流程图对比：ScanDMM vs AdaptiveScanDMM（简洁版）

## 📊 原始 ScanDMM 流程

```
输入：360度图像 I
    │
    ▼
┌──────────────────┐
│   Sphere_CNN     │  ← 一次性提取全图特征
│   (100%成本)     │     输出: 100维
└────────┬─────────┘
         │
         ▼
    img_features
    (100维，固定)
         │
         ├─────────────────┐
         │                 │
         ▼                 ▼
┌──────────────┐   ┌──────────────┐
│   t=1:       │   │   t=2,...,20:│
│  使用img_f   │   │  使用img_f   │
│  (相同)      │   │  (相同)      │
└──────────────┘   └──────────────┘
         │                 │
         └────────┬────────┘
                  ▼
           状态转移 → 生成注视点

特点：所有时间步使用相同的特征
```

## 🟢 改进后 AdaptiveScanDMM 流程

```
输入：360度图像 I
    │
    ▼
┌──────────────────┐
│   粗CNN          │  ← 快速提取粗特征
│   (30%成本)      │     输出: 50维
└────────┬─────────┘
         │
         ▼
    s_coarse
    (50维，固定，复用)
         │
         ├─────────────────┬─────────────────┐
         │                 │                 │
         ▼                 ▼                 ▼
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  t=1-5:      │   │  t=6:        │   │  t=7,...,20: │
│  使用粗特征   │   │  提取局部区域 │   │  提取局部区域 │
│  (快速)      │   │  → 细特征     │   │  → 细特征     │
│              │   │  → 融合特征   │   │  → 融合特征   │
└──────────────┘   └──────────────┘   └──────────────┘
         │                 │                 │
         └────────┬────────┴────────┬────────┘
                  │                 │
                  ▼                 ▼
           状态转移 → 生成注视点

特点：初始阶段快速，后续阶段动态提取局部特征
```

---

## 🔄 核心差异对比

### 特征提取阶段

**原始 ScanDMM：**
```
图像 I → [Sphere_CNN] → img_features (100维)
         ↑
      100%成本，一次性，固定
```

**改进后 AdaptiveScanDMM：**
```
图像 I → [粗CNN] → s_coarse (50维)
         ↑
      30%成本，一次性，固定
```

### 状态转移阶段

**原始 ScanDMM：**
```
循环中：
  z_t = GatedTransition(z_{t-1}, img_features)
                          ↑
                      固定，所有t相同
```

**改进后 AdaptiveScanDMM：**
```
循环中：
  if t <= 5:
    s = Pad(s_coarse)  ← 粗特征
  else:
    提取局部区域 → 细特征 → 融合
    s = Fusion(s_coarse, s_fine)  ← 动态特征
  z_t = GatedTransition(z_{t-1}, s)
                          ↑
                      每个t不同
```

---

## 📈 关键改进点

| 对比项 | 原始ScanDMM | AdaptiveScanDMM |
|--------|------------|----------------|
| **初始特征提取** | 100%成本，100维 | 30%成本，50维 |
| **特征类型** | 全局特征（固定） | 粗特征+细特征（动态） |
| **后续处理** | 复用固定特征 | 动态提取局部特征 |
| **计算成本** | 固定100% | 初始30% + 动态20%/步 |
| **信息丰富度** | 只有全局信息 | 全局+局部信息 |

---

## 🎯 一句话总结

**原始ScanDMM**：一次性提取全图特征，所有时间步使用相同的特征。

**AdaptiveScanDMM**：初始快速提取粗特征，后续根据注视点动态提取局部细特征并融合，每个时间步使用不同的特征。
