## 🔍 1. get_img_patches - 图像 Patch 提取

### 功能
从原始图像中提取指定位置的 patch（局部区域）。

### 代码解析

```python
def get_img_patches(self, input_frames, actions, patch_size, image_size):
    """
    参数:
        input_frames: (B, 3, H, W) 原始图像，例如 (B, 3, 288, 288)
        actions: (B, 4) 动作，包含 [x, y, scale_x, scale_y]
        patch_size: int patch 尺寸，例如 112
        image_size: int 原始图像尺寸，例如 288
    
    返回:
        patches: (B, 3, patch_size, patch_size) 提取的图像 patch
        _grid: 特征网格坐标（用于特征恢复）
        recover_feature_grid: 恢复特征用的网格坐标
    """
    batchsize = actions.size(0)
    
    # 创建仿射变换矩阵 theta (2×3)
    theta = torch.zeros((batchsize, 2, 3), device=input_frames.device)
    
    # 缩放因子（当前实现中固定为1，不使用缩放）
    patch_scale = torch.ones_like(actions[:, 2:4])  # (B, 2)
    
    # 计算 patch 在原图中的坐标
    # actions[:, :2] 是归一化的坐标 [0, 1]
    patch_coordinate = (actions[:, :2] * (image_size - patch_size * patch_scale))
    # 例如: [0.5, 0.5] * (288 - 112) = [88, 88]
    
    # 计算 patch 的四个角坐标
    x1 = patch_coordinate[:, 1]                           # 左上角 x
    x2 = patch_coordinate[:, 1] + patch_size * patch_scale[:, 1]  # 右下角 x
    y1 = patch_coordinate[:, 0]                           # 左上角 y
    y2 = patch_coordinate[:, 0] + patch_size * patch_scale[:, 0]  # 右下角 y
    
    # 构建仿射变换矩阵
    # 缩放
    theta[:, 0, 0] = patch_size * patch_scale[:, 1] / image_size  # x 方向缩放
    theta[:, 1, 1] = patch_size * patch_scale[:, 0] / image_size  # y 方向缩放
    
    # 平移（将 patch 中心映射到原点）
    theta[:, 0, 2] = -1 + (x1 + x2) / image_size  # x 方向平移
    theta[:, 1, 2] = -1 + (y1 + y2) / image_size  # y 方向平移
    
    # 创建采样网格并提取 patch
    grid = F.affine_grid(
        theta.float(), 
        torch.Size((batchsize, 1, patch_size, patch_size))
    )
    patches = F.grid_sample(input_frames, grid, mode='bicubic')
    # 输出: (B, 3, patch_size, patch_size)
    
    # 创建特征级别的网格（用于特征恢复）
    _grid = F.affine_grid(
        theta.float(), 
        torch.Size((batchsize, 1, self.focus_feature_size, self.focus_feature_size))
        # focus_feature_size = 112 // 16 = 7
    )
    
    # 将网格坐标从 [-1, 1] 转换到 [0, feature_size-1]
    recover_feature_grid = ((_grid + 1) / 2 * (self.glance_feature_size - 1)).permute(0, 3, 1, 2)
    # 输出: (B, 2, 7, 7)
    
    return patches, _grid, recover_feature_grid
```

### 关键步骤

1. **坐标转换**:
   - 输入: 归一化坐标 `[x, y]` ∈ [0, 1]
   - 转换: `实际坐标 = 归一化坐标 × (图像尺寸 - patch尺寸)`
   - 例如: `[0.5, 0.5]` → `[88, 88]` (在 288×288 图像中)

2. **仿射变换**:
   - 使用 `F.affine_grid` 创建采样网格
   - 将 patch 区域映射到标准网格 [-1, 1]
   - 使用双三次插值提取 patch

3. **特征网格**:
   - 同时生成特征级别的网格坐标
   - 用于后续的特征恢复操作

## 🔄 2. get_reuse_faet - 特征复用

### 功能
从全局特征图中提取与 patch 对应区域的特征，作为 Focus Net 的上下文信息。

### 代码解析

```python
def get_reuse_faet(self, input_faet, reuse_feat_grid, focus_step_index):
    """
    参数:
        input_faet: (B, L, C) 全局特征，例如 (B, 49, 384)
        reuse_feat_grid: 特征网格坐标，用于采样
        focus_step_index: 当前步骤索引
    
    返回:
        feat_to_reuse: (B, 49, 384) 复用特征（作为 Focus Net 的上下文）
    """
    B, L, C = input_faet.shape  # B=batch, L=49, C=384
    
    # 归一化
    input_faet = self.policy_net_recover_reuseNorm_list[focus_step_index](input_faet)
    
    # reshape 为特征图格式
    # (B, 49, 384) → (B, 384, 7, 7)
    input_faet = input_faet.permute(0, 2, 1).reshape(B, C, 7, 7).contiguous()
    
    # 深度可分离卷积处理
    input_faet = self.policy_net_recover_reuseConvHead(input_faet)
    # (B, 384, 7, 7) → (B, 384, 7, 7)
    
    # 使用网格采样提取对应区域的特征
    feat_to_reuse = F.grid_sample(
        input_faet,      # (B, 384, 7, 7)
        reuse_feat_grid, # 采样网格坐标
        mode='bilinear'
    )
    # 输出: (B, 384, 7, 7)
    
    # reshape 回序列格式
    feat_to_reuse = feat_to_reuse.reshape(B, C, 49).permute(0, 2, 1).contiguous()
    # 输出: (B, 49, 384)
    
    return feat_to_reuse
```

### 设计意图

1. **上下文提供**:
   - Focus Net 处理局部 patch 时，需要全局上下文信息
   - 从全局特征图中提取对应区域的特征
   - 帮助 Focus Net 理解局部区域在全局中的位置

2. **特征对齐**:
   - 使用双线性插值进行特征采样
   - 确保提取的特征与 patch 位置对齐

## 🗺️ 3. window_neighbor_grid - 邻域网格计算

### 功能
计算局部特征恢复时需要考虑的邻居位置，用于特征融合。

### 代码解析

```python
def window_neighbor_grid(self, B, sub_grid, window_size, feature_size):
    """
    参数:
        B: batch size
        sub_grid: (B, 2, window_size, window_size) patch 在全局特征图中的位置
        window_size: 局部特征图尺寸，例如 7
        feature_size: 全局特征图尺寸，例如 7
    
    返回:
        neighbor_coords_index: (B, 49, 25) 邻居位置的一维索引
        outlier_mask: (B, 49, 25) 掩码，标记是否超出边界
    """
    grid = sub_grid  # (B, 2, 7, 7) - patch 的位置坐标
    
    # 计算每个位置的邻居坐标
    # offset_xy: (1, 2, 1, 1, 25) - 5×5 的偏移量
    neighbor_coords = (grid + 0.5).int().unsqueeze(-1) + self.offset_xy
    # (B, 2, 7, 7, 25)
    
    # reshape
    neighbor_coords = neighbor_coords.reshape(
        B, 2, window_size * window_size * self.recover_n * self.recover_n
    )
    # (B, 2, 49*25) = (B, 2, 1225)
    
    # 检查哪些邻居位置超出边界
    outlier_index = (
        (neighbor_coords[:, 0] >= 0) & 
        (neighbor_coords[:, 1] >= 0) & 
        (neighbor_coords[:, 0] <= (feature_size - 1)) & 
        (neighbor_coords[:, 1] <= (feature_size - 1))
    )
    # (B, 1225) - bool 类型
    
    # 转换为掩码
    outlier_mask = outlier_index.long().view(
        B, window_size * window_size, self.recover_n * self.recover_n
    )
    # (B, 49, 25)
    
    # 裁剪超出边界的坐标
    neighbor_coords = torch.clamp(
        neighbor_coords, 
        min=0, 
        max=(feature_size - 1)
    )
    
    # 将 2D 坐标转换为一维索引
    # index = x + y * feature_size
    neighbor_coords_index = (
        neighbor_coords[:, 0, :] + 
        neighbor_coords[:, 1, :] * feature_size
    )
    # (B, 1225)
    
    # reshape
    neighbor_coords_index = neighbor_coords_index.view(
        B, window_size * window_size, self.recover_n * self.recover_n
    )
    # (B, 49, 25)
    
    return neighbor_coords_index, outlier_mask
```

### 可视化理解

假设 `recover_n=5`，对于局部特征图的每个位置，考虑其 5×5 的邻居：

```
全局特征图 (7×7)             局部 patch 位置 (x, y)
┌─────────────┐              ┌───────────┐
│             │              │           │
│    ●●●      │  恢复时考虑  │    ●      │
│    ●■●      │  ←───────────│    ■      │
│    ●●●      │   5×5邻居    │    ●      │
│             │              │           │
└─────────────┘              └───────────┘
```

**offset_xy 示例** (recover_n=5):
```
[[-2, -2], [-2, -1], [-2, 0], [-2, 1], [-2, 2],
 [-1, -2], [-1, -1], [-1, 0], [-1, 1], [-1, 2],
 [ 0, -2], [ 0, -1], [ 0, 0], [ 0, 1], [ 0, 2],
 [ 1, -2], [ 1, -1], [ 1, 0], [ 1, 1], [ 1, 2],
 [ 2, -2], [ 2, -1], [ 2, 0], [ 2, 1], [ 2, 2]]
```

## 🎯 4. evaluate_policy_net - 策略网络评估

### 功能
用于 PPO 训练时，重新评估旧动作的对数概率和状态价值。

### 代码解析

```python
def evaluate_policy_net(self, seq_l=None, old_states=None, old_actions=None, 
                        batch_index=None, ppo_std_this_iter=None):
    """
    参数:
        seq_l: 序列长度
        old_states: 旧状态列表 [state_0, state_1, ..., state_{seq_l-1}]
        old_actions: 旧动作列表 [action_0, action_1, ..., action_{seq_l-1}]
        batch_index: 批次索引（用于小批量更新）
        ppo_std_this_iter: 动作噪声标准差
    
    返回:
        logprobs: (B, seq_l) 旧动作在新策略下的对数概率
        state_values: (B, seq_l) 状态价值
        dist_entropy: (B, seq_l) 分布熵
    """
    logprobs = []
    state_values = []
    dist_entropy = []
    
    for focus_step_index in range(seq_l):
        # 获取当前步骤的状态
        input_feat = old_states[focus_step_index][batch_index]  # (B', 49, 384)
        B, L, C = input_feat.shape
        
        with torch.cuda.amp.autocast(enabled=True):
            # 评估状态价值
            _state_values = self.policy_net_patch_stateV(
                (self.policy_net_patch_norm_list_stateV[focus_step_index](
                    input_feat.detach())
                ).permute(0, 2, 1).reshape(B, C, 7, 7).contiguous(),
                focus_step_index
            )
            state_values.append(_state_values)  # (B', 1)
            
            # 评估动作（策略网络输出）
            _actions = self.policy_net_patch(
                (self.policy_net_patch_norm_list[focus_step_index](
                    input_feat.detach())
                ).permute(0, 2, 1).reshape(B, C, 7, 7).contiguous(),
                focus_step_index
            )  # (B', 2)
            
            actions = _actions.clone()
            
            with torch.cuda.amp.autocast(enabled=False):
                actions = actions.float()
                
                # 创建多元高斯分布
                action_var = torch.full(
                    (2,), ppo_std_this_iter, device=input_feat.device
                )
                cov_mat = torch.diag(action_var)
                dist = torch.distributions.multivariate_normal.MultivariateNormal(
                    actions, scale_tril=cov_mat
                )
                
                # 计算旧动作在新策略下的对数概率
                logprobs.append(
                    dist.log_prob(old_actions[focus_step_index][batch_index]).unsqueeze(-1)
                )  # (B', 1)
                
                # 计算分布熵（用于正则化）
                dist_entropy.append(dist.entropy().unsqueeze(-1))  # (B', 1)
    
    # 拼接所有步骤的结果
    logprobs = torch.cat(logprobs, dim=1)      # (B', seq_l)
    state_values = torch.cat(state_values, dim=1)  # (B', seq_l)
    dist_entropy = torch.cat(dist_entropy, dim=1)  # (B', seq_l)
    
    return logprobs, state_values, dist_entropy
```

### 用途

在 PPO 训练中，需要计算**重要性采样比率**:
```
r_t = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)
```

这个函数用于计算分子部分（新策略下的概率），分母是前向传播时保存的旧概率。

## 📊 5. 特征恢复机制详解

特征恢复是将局部特征融合回全局特征图的关键步骤：

```python
# 1. 生成恢复权重
recover_policy_weight = self.policy_net_recover(
    self.policy_net_recover_preLN_list[focus_step_index](local_features)
)
# (B, 49, 25) - 每个局部位置预测一个 5×5 的权重矩阵

# 2. 计算邻居坐标
neighbor_coords_index, outlier_mask = self.window_neighbor_grid(
    B, grid, self.focus_feature_size, self.glance_feature_size
)

# 3. 应用掩码
recover_policy_weight = recover_policy_weight * outlier_mask

# 4. 构建权重矩阵 (B, 49, 49)
relative_position_weight = torch.zeros(
    (B, 49, 49), device=...
).scatter_add_(
    dim=2, 
    index=neighbor_coords_index,  # (B, 49, 25)
    src=recover_policy_weight     # (B, 49, 25)
).permute(0, 2, 1)

# 5. 特征融合
updated_features = relative_position_weight @ local_features + updated_features
```

### 直观理解

```
局部特征 (B, 49, 384)          权重矩阵 (B, 49, 49)          全局特征 (B, 49, 384)
┌─────────────┐               ┌─────────────┐              ┌─────────────┐
│ f_0         │               │ w_00 w_01...│              │ g_0         │
│ f_1         │     ×         │ w_10 w_11...│     +        │ g_1         │
│ ...         │               │ ...         │              │ ...         │
│ f_48        │               │ w_48,0 ...  │              │ g_48        │
└─────────────┘               └─────────────┘              └─────────────┘
      ↓                              ↓                            ↓
  局部特征                        注意力权重                    全局特征
                                    ↓
                            更新后的全局特征 = W @ f + g
```

**关键点**:
- 每个局部特征位置 `f_i` 通过权重矩阵 `W[i, :]` 分配到全局特征的所有位置
- 权重矩阵是**稀疏的**，只对邻居位置有非零权重
- 通过加权求和融合局部和全局信息

## 📝 总结

这些关键组件共同实现了 AdaptiveNN 的核心功能：

1. **get_img_patches**: 实现空间注意机制，提取关键区域
2. **get_reuse_faet**: 提供全局上下文信息
3. **window_neighbor_grid**: 实现特征融合的空间映射
4. **evaluate_policy_net**: 支持 PPO 训练的重要性采样
5. **特征恢复机制**: 实现局部到全局的信息融合

所有这些组件都是端到端可训练的，通过梯度反向传播联合优化。
